A one-line pickup line aimed at a robot — a Roomba that mapped the whole house just to bump into its crush — written by a small deterministic Node program. Entry for the [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/competitions/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) bounty on make.fun.

## The text

```text
Roomba, you mapped the whole house just to bump into me — smooth.
```

65 characters, 67 bytes, no trailing newline. The line talks straight to the robot: mapping and bumping are two real Roomba behaviours, reframed as deliberate flirting, and the one-word punch ("smooth") calls its game. The line was picked by an internal sparring tournament (two rival drafters, a rival critic, head-to-head duels under the kit judge's brief in both orders); the full record is in `duel-test.md`.

## Run it

Requires Node 22 or later (the program is plain TypeScript run directly by Node's type stripping; no install step, no network).

```sh
node main.ts
cat /output/entry.txt
```

Run it twice and the output is byte-identical.
